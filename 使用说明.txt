语义相册 · Windows 本地版 — 使用说明
======================================

一、这是什么
--------------------------------------
一个跑在本机的相册：打开就是照片墙，找东西时才用一句中文去搜
（照片、视频、音频都能搜），并且自动按 人像 / 城市 / 场景 / 事物 分类。
所有文件只在本机读取，不上传、不联网
（只有「查城市名」这一步需要联网，断网也能用，只是不显示城市名）。

二、安装
--------------------------------------
方式一（推荐）：双击「语义相册Setup.exe」
   - 一路「下一步」即可，默认装到 当前用户\AppData\Local\Programs\语义相册
     （装在自己的用户目录，无需管理员权限，也不用点 UAC）
   - 会自动创建桌面和开始菜单快捷方式
   - 卸载：系统设置 → 应用 → 语义相册 → 卸载

方式二（便携包）：解压「语义相册.zip」到任意目录，直接双击 语义相册.exe
   - 整个文件夹可以拷到 U 盘/别的电脑直接用（含模型和索引）

三、界面长什么样
--------------------------------------
顶栏从左到右：
   语义相册   照片   时刻   人像   城市   场景   事物        [搜索]  [⋯]

   照片  ── 首屏照片墙，按月份分组；往下滚自动加载更多
   时刻  ── 按「拍摄时间 + 地点」自动切出来的事件，
             一次出行、一场聚会就是一张卡片（详见第六节）
   人像 / 城市 / 场景 / 事物
          ── 智慧相册的四大分类，数字是分组个数；
             点进去是封面卡片，再点一张进分组看全部照片
   搜索  ── 弹出搜索框（也能直接按 / 键打开）
   ⋯     ── 侧边抽屉：状态、照片文件夹、建索引、相册重建、
             重复照片、应用（日志/重开窗口/退出）

点开任意一张：
   大图/视频播放，左右箭头或 ← → 键切换上一张下一张；
   底部显示 时间、大小尺寸、拍摄地点、标签、人物；
   右上有「找相似」（拿这张去找同类画面）、打开原文件、另存为、删除。

四、第一次用
--------------------------------------
1. 双击桌面「语义相册」
   程序在后台运行，不会弹黑窗口。几秒后会自动用 Edge 开一个没有地址栏的
   独立窗口当界面（电脑上没有 Edge 就退回默认浏览器）。
   万一窗口没出来：再双击一次程序图标即可，它不会重复启动，
   只会把已有的界面窗口拉出来。

   怎么退出：
     直接关掉界面窗口就行 —— 后台进程会跟着一起退出。
     也可以点 界面右上角 ⋯ →「退出语义相册」，效果一样
     （窗口关不掉、或者从手机浏览器看界面时用这个）。
   日志在哪：
     程序目录\data\logs\app.log（界面 ⋯ →「打开日志」直接打开所在文件夹）
   想看实时日志：
     命令行执行  语义相册.exe --console   会额外开一个控制台窗口。

2. 点右上角「⋯」→ 在「照片文件夹」里添加要收录的目录
   例如：E:\相册 、 E:\相册\相机照片 、 此电脑\图片 、 D:\照片
   （可以添加多个目录；这里也有快捷按钮，点了直接填）

3. 点「建立索引」
   - 照片：很快（本机 MX250 独显加速，约 115 毫秒/张；没加速也能跑，只是慢 3~4 倍）
     抽屉「模型」一行会显示「就绪 · GPU 加速」，说明独显在干活
   - 视频/音频：慢在音轨转文字（Whisper，约 5~10 倍实时），
     进度里有日志，可以放着不管
   - 索引过程中随时可以看照片墙、搜索已建好的部分

4. 出智慧相册（分类）
   抽屉「智慧相册」里先点「只更新标签 + 城市」，约 1 分钟，
   顶栏的人像/城市/场景/事物就有内容了（「时刻」也在这步一起生成）；
   想要人像，再点「全部重建」扫人脸（每张 0.2~0.5 秒，几百张几分钟）。
   之后新文件丢进目录，最多 5 分钟自动出现在照片墙和搜索里。

   从旧版本升级上来时，人脸识别算法换了（加了 5 点对齐和密度约束），
   第一次打开会自动在后台重扫一遍人脸（几千张约 10~30 分钟，不影响其它功能），
   期间人像页可能显示不全，扫完就正常了。你之前起过的名字和手动改过的分组
   都会保留。

5. 想清清硬盘
   抽屉 →「重复照片」→「扫描」，会按图像指纹把同一张图的多份、
   同一张海报的不同版本找出来。
   每张缩略图上带蓝框的是「建议保留」，确认后点「清理」，
   其余的移进 data\trash\（不是硬删，能拷回来）。

五、怎么搜
--------------------------------------
· 打字搜：「雪地里的猫」「生日蛋糕」「海边的日落」
· 搜文件名也行：直接打 IMG_2025、DSC、或者目录名，
  名称里带这几个字的照片会被优先排上来
  （比如打「IMG_20251207」能直接找到当天的照片）
· 点 🎤 说话，语音直接搜（转写后按内容搜）
· 「以图搜图」：上传一张图找相似画面
· 灯箱里「找相似」：不用上传，直接拿当前这张去找
· 搜索框下面的「全部 / 照片 / 视频 / 音频」是类型筛选
  （视频里说的话也能搜到，卡片上会显示转写的那句话）
· 结果只有前几张是真正相关的，剩下的会折叠成
  「还有 N 项相关度较低 · 展开」，点一下才展开
· 搜过的话会记在搜索框下面的「最近」里（最多 8 条），
  点一下就再搜一次；点「清除」清空。
  这些只存在本机浏览器里，不联网、不上传。

六、时刻（自动分事件）
--------------------------------------
不用自己整理相册，「时刻」会自动把时间挨着、地点一样的照片
归成一个个事件：
   一次周末出行、一场生日聚会、某天下午连着拍的一批 —— 各是一张卡片。
   标题长这样：「2025年12月7日 · 苏州市」

规则（都是一句话能讲明白的）：
· 相邻两张照片的拍摄时间差超过 6 小时，就断成两个事件；
· 一个事件里少于 3 张照片的，不单独列（免得满屏两秒钟的碎段）；
· 地点取这个事件里 GPS 查到的城市，没有 GPS 就只写日期。

想调松/调紧（比如出行一整天想归成一个事件）：
   命令行 set EVENT_GAP=12  然后启动程序，就放宽到 12 小时。
   想让小事件也显示：set EVENT_MIN=2

七、文件都放在哪
--------------------------------------
程序目录\data\media.db   索引和向量（删掉它 = 重建索引）
程序目录\data\thumbs\    缩略图
程序目录\data\trash\     回收站：界面里「删除」的文件移到这里，能拷回去
程序目录\models\         模型文件（clip / whisper / face）

（安装版默认在 当前用户\AppData\Local\Programs\语义相册）

八、人像分组不准怎么办
--------------------------------------
识别再准也总会出错，所以界面上留了手动纠正的口子：

· 这张照片里不是他
    进「人像」→ 点开某个人 → 每张照片左上角有「✕ 不是他」。
    点了会让你选：这其实是谁（列出所有人物，选一个就归过去）
                  都不是 · 单独新建一组（拆出来，之后可以再归到别人）
                  这些不是人 · 别出现在人像里（海报、动画截图里的卡通脸就点这个）

· 两个人被拆成了两组
    人像页人物卡片上点「合并」，选目标人物，两组就并成一组。

· 同一个人被拆成好几组
    分别给它们起同一个名字（卡片上的「命名」），同名会自动合并。

· 一组里混进了别人
    进到那一组，把不对的照片逐张点「✕ 不是他」。
    每次只影响这一张照片里属于这组的脸，合影里别人的脸不会被误伤。

· 一堆没人认领的脸在哪
    人像页最末尾有张「其他面孔」卡片，点进去是所有"有脸但没归到任何人"的
    照片 —— 路人、合照里的陌生人、卡通角色、只出现过一次的侧脸都在这里。
    点一张可以认领到已有的某个人，或者给它单独建一组。
    这么做是因为：只有一张脸、没有任何相似脸的，多半是误检，
    硬凑成一个人物只会让人像页越来越脏，所以单独收着，不占人物卡片。

· 一个人只有一张照片，被收进「其他面孔」了
    这是有意为之：算法要求同一个人至少有 2 张相似的脸才建人物。
    想让它出现，在「其他面孔」里点那张脸，选「单独建一组」即可。
    反过来，如果你的库很小（少于 12 张脸），程序会自动放宽到 1 张，
    免得刚建完索引人像页是空的。

· 识别是怎么判的（知道原理才好纠）
    先按眼睛鼻子嘴的位置把脸摆正，再算两张脸的相似度；
    不光看两张脸像不像，还要求两组人"整体上"够像才合并，
    所以不会出现 A 像 B、B 像 C 就把 A 和 C 串成一个的情况。
    侧脸、模糊、戴墨镜、化了浓妆的脸最容易判错 —— 手动纠正一下就好。
    你手动改过的分组会被记住：重建索引时不会被算法拆散，
    手工拆出去的那组也不会再被自动吸回去。

九、常见问题
--------------------------------------
· 界面打不开？
  先再双击一次程序图标（会把日志里记着的那次启动的窗口拉出来）；
  还是不行就看 程序目录\data\logs\app.log 最后几行
  （⋯ →「打开日志」能直接打开这个文件夹）。
  确认没有杀毒软件拦截（未签名程序，SmartScreen 选「更多信息 → 仍要运行」）。
· 想换电脑/拷给别人：安装版用安装包；便携包整个文件夹拷走即可。
· 想彻底重建：退出程序 → 删掉 data 文件夹 → 重新打开 → 建索引。
· 某个分类的封面是空白：点一次 抽屉 → 智慧相册 →「只更新标签 + 城市」。
· 手机/平板想一起用：同一局域网下访问 http://<电脑IP>:8765。
  删除/命名会直接动电脑上的文件，别乱点。
· 显存不够/驱动抽风：程序会自动回退 CPU 继续跑，只是慢一些
  （模型一行会显示「CPU 模式」）。
· 想确认独显有没有用上：看抽屉「模型」是不是「就绪 · GPU 加速」。
· 报「DLL 初始化例程失败」/ 模型一行显示「CPU 模式（DirectML 不可用）」：
  说明本机的 DirectX 12 / 显卡驱动起不来 DirectML（远程桌面、虚拟机、
  老驱动都会这样）。程序自带一份纯 CPU 版，会自动接管，功能一个不少，
  只是建索引慢 3~4 倍。想强制走 CPU 也可以：
     命令行执行  set AIWIN_ORT=cpu  然后 语义相册.exe

十、会占多少资源
--------------------------------------
内存：CLIP 约 300MB（GPU 共享内存）+ Whisper 按需约 200MB，共 <1.5GB
磁盘：程序 + 模型约 1.5GB，缩略图每张约 20KB，索引约 60KB/千文件
